# 常用链接签到页

这是一个无需安装、可直接用浏览器打开的静态网页。网页中已经放入两条链接：

1. 视频号内容：<https://weixin.qq.com/sph/AQk4HX6E6v>
2. 微信公众号文章：<https://mp.weixin.qq.com/s/YeI2lXYCQ9_Zal0_oq1USA>

## 批量生成链接

打开网页后，在“批量生成链接窗口”里粘贴链接，用英文分号 `;`、中文分号 `；` 或换行分隔，然后点击“生成链接”。页面会自动生成最多 6 个可点击窗口；超过 6 个时只取前 6 个。

## 使用方法

双击打开 `index.html`，或把整个 `link-checkin` 文件夹部署到任意静态网页空间。

使用者先点击“打开链接”查看内容，再填写姓名并点击“确定签到”。查看状态、姓名和签到时间会保存到当前浏览器的本地存储中。

生成后的链接列表和签到记录会保存在当前浏览器中，下次打开页面仍会保留。

## 重要边界

当前版本是纯前端静态页面，签到记录只保存在每个人自己的浏览器里，因此不同人之间不会自动看到同一份签到名单。若要汇总所有人的签到结果，需要把保存逻辑改为在线表单、云函数或数据库。
